# XIUD — Official Pre-Launch Website & Portal

Portal oficial e página institucional de pré-lançamento da **XIUD (XIU Development)** — organização de engenharia de software de alto padrão, sistemas distribuídos e ecossistemas orientados por agentes autônomos de inteligência artificial.

![XIUD Cover](/public/logo.png)

---

## 🏛️ Sobre a XIUD

A **XIUD (XIU Development)** é liderada por **Gabriel Aragão (`@domaragao`)** (CEO & CTO) e opera com squads de engenharia integradas a agentes autônomos cognitivos (**Core Staff XIUD**).

- **Missão:** Projetar, desenvolver e escalar aplicações web ultrarrápidas, produtos SaaS de alto valor agregado e arquiteturas multi-agentes autônomas.
- **Identidade Visual:** *Tech-Noir / Neo-Heraldic Cyberpunk* — midnight obsidian, champagne gold, cybernetic traces e precisão cirúrgica de pixels.

---

## ⚡ Stack Tecnológica

- **Framework / Core:** [React 19](https://react.dev/) + [Vite 6](https://vite.dev/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Estilização & UI:** [Tailwind CSS v3](https://tailwindcss.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Micro-interações:** Canvas Particles + [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Hospedagem & CDN:** [Vercel](https://vercel.com/) (Edge Network)
- **Controle de Versão:** [GitHub](https://github.com/xiud-bots/xiud-website)

---

## 🚀 Funcionalidades da Página de Pré-Lançamento

1. **Header com Status Operacional:** Indicador pulsante em tempo real (`BUILDING // PRE-LAUNCH`).
2. **Hero com Brasão Oficial XIUD:** Iluminação volumétrica, halo de luz gradiente e tipografia de alto impacto.
3. **Formulário de Lista de Espera (Early Access):** Validação de e-mail, micro-animações, geração de protocolo único (`XIUD-XXXX-ALPHA`), confetes dourados e persistência local.
4. **Telemetria de Sistema:** Indicadores visuais de progresso de engenharia, arquitetura de núcleo e status da rede de agentes.
5. **Pilares Estratégicos:** 3 blocos conceituais detalhando as frentes de atuação da XIUD (Engenharia Web & Cloud, Agentes Autônomos e Produtos SaaS).
6. **Terminal Interativo XIUD (`xiud-console`):** Console interativo que aceita comandos como `help`, `about`, `status`, `agents`, `stack`, `founder` e `contact`, com chips de atalho.
7. **Roadmap & Canal de Contato:** Prévia de lançamentos futuros e link direto para a diretoria (`gabriel@xiud.com`).

## 🛠️ Comandos de Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento local
npm run dev

# Gerar build otimizado de produção
npm run build

# Pré-visualizar build localmente
npm run preview
```

## 📦 Deploy na Vercel

O projeto foi configurado para deploy automático na Vercel:

```bash
# Deploy em produção via Vercel CLI
vercel --prod
```
