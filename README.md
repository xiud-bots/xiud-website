# XIUD — Official Pre-Launch Website & Portal

Portal oficial e página institucional de pré-lançamento da **XIUD (XIU Development)** — organização de engenharia de software de alto padrão, sistemas distribuídos e ecossistemas orientados por inteligência artificial.

![XIUD Cover](/public/logo.png)

---

## 🏛️ Sobre a XIUD

A **XIUD (XIU Development)** projeta, desenvolve e escala aplicações web ultrarrápidas, produtos digitais corporativos e arquiteturas de software de alta resiliência.

- **Missão:** Engenharia de software com precisão, confiabilidade e excelência técnica.
- **Identidade Visual:** *Tech-Noir / Neo-Heraldic Cyberpunk* — midnight obsidian, champagne gold, cybernetic traces e acabamento pixel-perfect.

---

## ⚡ Stack Tecnológica

- **Framework / Core:** [React 19](https://react.dev/) + [Vite 6](https://vite.dev/)
- **Linguagem:** [TypeScript](https://www.typescriptlang.org/) (Strict Mode)
- **Estilização & UI:** [Tailwind CSS v3](https://tailwindcss.com/)
- **Ícones:** [Lucide React](https://lucide.dev/)
- **Micro-interações:** Canvas Particles + [Canvas Confetti](https://www.npmjs.com/package/canvas-confetti)
- **Hospedagem & CDN:** [Vercel](https://vercel.com/) (Edge Network)
- **Controle de Versão:** [GitHub](https://github.com/xiud-bots/xiud-website)

---

## 🚀 Funcionalidades da Página de Pré-Lançamento

1. **Header com Status Operacional:** Indicador pulsante em tempo real (`BUILDING // PRE-LAUNCH`).
2. **Hero com Brasão Oficial XIUD:** Iluminação volumétrica, halo de luz gradiente e tipografia de alto impacto.
3. **Formulário de Lista de Espera (Early Access):** Validação de e-mail, micro-animações, geração de protocolo único (`XIUD-XXXX-ALPHA`), confetes dourados e persistência local.
4. **Telemetria de Sistema:** Indicadores visuais de progresso de engenharia, arquitetura de núcleo e status dos serviços.
5. **Pilares Estratégicos:** 3 blocos conceituais detalhando as frentes de atuação da XIUD (Engenharia Web & Cloud, Inteligência & Automação e Produtos SaaS).
6. **Terminal Interativo XIUD (`xiud-console`):** Console interativo que aceita comandos como `help`, `about`, `status`, `stack` e `contact`, com chips de atalho.
7. **Roadmap & Canal de Contato:** Prévia de lançamentos futuros e link direto para atendimento comercial (`xiudsales@gmail.com`).

## 🛠️ Comandos de Desenvolvimento

```bash
# Instalar dependências
npm install

# Iniciar servidor de desenvolvimento local
npm run dev

# Gerar build otimizado de produção
npm run build

# Pré-visualizar build localmente
npm run preview
```

---

## 📦 Deploy na Vercel

O projeto está configurado com continuous deployment na Vercel Edge:

```bash
# Deploy em produção via Vercel CLI
vercel --prod
```
